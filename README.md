# MIKHALEFF — digital gallery

Local development repository for the new [mikhaleff.art](https://mikhaleff.art) portfolio. The site uses Next.js App Router, TypeScript, Sanity, GSAP, Lenis and Motion. Vite is not used.

## Local development

Requirements: Node.js 22+ and pnpm 11+.

```bash
pnpm install
pnpm dev
```

The usual preview URL is `http://localhost:3000/en`. A different port can be passed to Next.js, for example `pnpm dev -- -p 5173`.

Quality checks:

```bash
pnpm typecheck
pnpm lint
pnpm build
```

## Content and Sanity

Until the real archive is entered, the public site uses typed fallback content from `lib/content/`. Generated studio and installation photographs in `public/studio/` and `public/exhibitions/` are temporary editorial placeholders and must be replaced with approved artist materials before launch.

Copy `.env.example` to `.env.local` and configure the Sanity project. Launch the editor with:

```bash
pnpm studio
```

The schema covers languages, artworks, series, exhibitions, journal entries, homepage sections, About, Contact and global settings. Artwork records also include placement controls for Exhibition mode.

### Editorial workflow

1. In **LANGUAGES**, create or enable a language and set its `code`, `slugPrefix`, locale and menu order. Only one language can be marked default. Localized fields automatically accept the same language records; missing translations fall back to English and then to the first available value.
2. In **ARTWORKS**, add identity, year, medium, dimensions and availability, then upload `mainImage`. Optional hero, gallery, texture, detail, interior and mobile variants control each context independently. Hotspot and crop are respected by Sanity’s image pipeline.
3. Create **SERIES** and order their artwork references. Optional Exhibition-mode scale/alignment fields are hints; the frontend still produces a curated composition when they are empty.
4. Create **EXHIBITIONS**, add location, dates, installation views and included works.
5. Use the **HOMEPAGE** singleton to select the hero work, statement, works and featured series. Navigation/contact defaults live in **SETTINGS**.

Recommended source images use a wide-gamut master when available, embedded sRGB profile for web delivery, meaningful localized alt text, and enough resolution for the largest intended placement. Do not bake typography into artwork images. Sanity/CDN and `next/image` produce responsive AVIF/WebP output; only the first-screen hero is preloaded.

Sanity preview uses `/api/draft?secret=...&redirect=/en`; disable it at `/api/disable-draft`. Webhooks can call `/api/revalidate` with the `x-sanity-secret` header and an optional JSON body such as `{ "paths": ["/en/works"] }`.

## Contact delivery

The validated contact form is delivered server-side over SMTP. Configure `MAIL_HOST`, `MAIL_PORT`, `MAIL_ENCRYPTION`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_FROM_ADDRESS`, and `INQUIRY_TO_EMAIL`. Credentials remain server-only; visitor email is used as `Reply-To`. The endpoint includes rate limiting, a honeypot, validation, and escaped HTML output.

## Theme and accessibility

Dark is the initial site default. The header control stores the visitor choice in `localStorage`; an inline pre-hydration script prevents a theme flash. Both themes use semantic CSS tokens, and artwork assets are never filtered. Keyboard focus, reduced-motion behavior, form status announcements and fullscreen artwork controls are included.

## Routes

- `/{locale}` — homepage
- `/{locale}/works` and `/{locale}/works/{slug}`
- `/{locale}/series` and `/{locale}/series/{slug}`
- `/{locale}/exhibitions` and `/{locale}/exhibitions/{slug}`
- `/{locale}/about`
- `/{locale}/journal` and `/{locale}/journal/{slug}`
- `/{locale}/contact`

Supported locale prefixes are `en`, `ru` and `zh`. English fallback copy is deliberate until translated Sanity fields are populated.

## SEO and release

Every public route emits a canonical URL, hreflang links including `x-default`, Open Graph and Twitter metadata. Artwork, artist, exhibition and journal detail routes emit Schema.org JSON-LD. `sitemap.xml` and `robots.txt` are generated by Next.js.

Before production launch:

- connect and populate the real Sanity project, replacing all marked placeholders;
- configure the inquiry webhook and verify mailbox delivery;
- collect indexed URLs from the current WordPress site and add permanent redirects in `next.config.ts`;
- run `pnpm typecheck`, `pnpm lint` and `pnpm build`;
- verify responsive layout, keyboard navigation, reduced motion, both themes and image crops on real devices;
- deploy to a Next.js-compatible host and set the same environment variables there;
- host Sanity Studio with `pnpm studio:build` or deploy it through Sanity’s standard hosted Studio flow.

No deployment is performed from this local phase. Server connection and legacy redirects should be completed only after hosting details and the old URL inventory are available.
